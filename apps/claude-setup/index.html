ℹ Comment fonctionne OpenRouter
OpenRouter est un service qui te donne accès à des dizaines d'IA avec une seule clé. Les modèles avec le suffixe :free sont gratuits, mais nécessitent un minimum de 5€ de crédit sur ton compte. Sans crédit, aucune IA ne fonctionnera.
⚠ Limites importantes à connaître
• Modèles gratuits : 50 requêtes/jour si moins de 10 crédits achetés, 1000/jour au-delà.
• Modèles payants : facturés au nombre de tokens générés. Surveille ton solde.
• Fallback automatique : si un modèle gratuit est saturé, OpenRouter peut te basculer sur un modèle payant sans préavis.
• Conseil : définis une limite de dépense dans ton compte OpenRouter (Settings → Spending Limit) pour éviter les surprises.

🎯 Comment utiliser /model pour changer d'IA
Le guide pas-à-pas pour les débutants qui ne parlent pas anglais.

📌 Nouveau : le menu de démarrage multi-IA

Si tu as installé plusieurs IA (onglet ① Ma clé / ② Mon IA ou ⚙ Modifier), Lancer Claude Code.ps1 affiche maintenant un petit menu numéroté à chaque démarrage. Tape le numéro de l'IA que tu veux, ou appuie directement sur Entrée pour utiliser ton IA par défaut. Toutes ces IA utilisent la même clé OpenRouter — pas besoin d'en recréer une.

📌 Pourquoi changer d'IA ?

Si ton IA actuelle est lente, surchargée ou ne répond plus, tu peux en essayer une autre gratuitement. C'est normal sur les IA gratuites — elles sont parfois saturées le soir.

📌 Commande /model — Le pas-à-pas

  1. Dans Claude Code, tape /model et appuie sur Entrée
  2. Une liste apparaît avec des numéros de 1 à 6
  3. Ignore les options 1 à 5 — ce sont les IA payantes d'Anthropic (Claude Opus, Sonnet, etc.)
  4. Descends jusqu'à l'option 6 qui s'appelle "Custom model" (modèle personnalisé)
  5. Appuie sur Entrée pour sélectionner l'option 6
  6. La console te demande : "Enter custom model ID:"
  7. Tape l'identifiant exact de ton IA, par exemple :
    deepseek/deepseek-v4-flash (DeepSeek V4)
    qwen/qwen3-coder:free (Qwen3 Coder)
    meta-llama/llama-3.3-70b-instruct:free (Llama 3.3)
  8. Appuie sur Entrée une fois que tu as tapé l'identifiant
  9. Claude Code va te demander si tu veux en faire ton modèle par défaut (toujours celui-là) ou juste pour cette session (une fois). Choisis "par défaut" si tu l'aimes bien.
💡 Raccourci : Tu peux aussi taper directement /model deepseek/deepseek-v4-flash en une seule fois, ça va plus vite !

📌 Que signifient les options 1 à 5 ?

Les options 1 à 5 correspondent aux modèles Claude Anthropic (Opus, Sonnet, Haiku...).
Ce sont les versions officielles de Claude, payantes (Anthropic facture à l'usage).
L'option 6 "Custom model" est celle qui utilise ta clé OpenRouter — donc gratuite.
Ne t'inquiète pas si tu vois des noms anglais dans la liste, le fonctionnement est simple.

🔧 Messages d'erreur expliqués (clique pour voir la solution)

"There's an issue with the selected model"

Ce qui se passe : Le modèle choisi n'est pas disponible ou n'est pas reconnu par OpenRouter.

Solution :
1. Tape /model dans Claude Code
2. Choisis l'option 6 "Custom model"
3. Tape un autre modèle (ex: qwen/qwen3-coder:free)
4. Si ça continue, va dans l'onglet ⚙ Modifier de cette application, choisis une autre IA, télécharge un nouveau lanceur.

"API error · Retrying in 2s · attempt X/10"

Ce qui se passe : L'IA gratuite est surchargée (trop de monde l'utilise en même temps). C'est normal, ça arrive surtout le soir.

Solutions :
1. Attends quelques secondes, Claude Code réessaie automatiquement (jusqu'à 10 fois)
2. Si ça continue, tape /model → option 6 → tape qwen/qwen3-coder:free (alternative)
3. Essaie à un autre moment de la journée (moins de monde)
4. Tu peux aussi essayer meta-llama/llama-3.3-70b-instruct:free — très disponible.

"openrouter/owl-alpha · API Usage Billing"

Ce qui se passe : Claude Code a sélectionné automatiquement Owl Alpha (le modèle par défaut d'OpenRouter). C'est normal — la connexion fonctionne !

Solution :
Tape simplement /model pour choisir ton IA préférée (DeepSeek V4, Qwen3 Coder, etc.). Voir le guide plus haut dans cet onglet.

"Authentication failed" ou "Invalid API key"

Ce qui se passe : Ta clé OpenRouter n'est pas reconnue.

Solutions :
1. Va sur openrouter.ai/keys et vérifie que ta clé est active
2. Si elle a expiré ou a été supprimée, crées-en une nouvelle
3. Va dans l'onglet ⚙ Modifier de cette application et colle ta nouvelle clé
4. Télécharge un nouveau lanceur et remplace l'ancien sur ton Bureau.

"Cannot be loaded because running scripts is disabled"

Ce qui se passe : Windows bloque l'exécution des scripts PowerShell. C'est une sécurité normale de Windows.

Solution :
1. Recherche "PowerShell" dans le menu Démarrer
2. Clic droit → "Exécuter en tant qu'administrateur"
3. Tape cette commande et appuie sur Entrée :
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
4. Réponds O (Oui) et appuie sur Entrée
5. Relance ton fichier .ps1

Le fichier .ps1 s'ouvre dans le Bloc-notes au lieu de s'exécuter

Ce qui se passe : Windows a associé les fichiers .ps1 au Bloc-notes au lieu de PowerShell.

Solution :
Utilise toujours le clic droit sur le fichier → "Exécuter avec PowerShell".
Ne double-clique jamais sur un fichier .ps1 — ça l'ouvre dans le Bloc-notes.

Claude Code demande de se connecter / "Login to continue"

Ce qui se passe : Claude Code détecte un conflit entre ta session Anthropic et la config OpenRouter.

Solution :
1. Dans Claude Code, tape /logout et appuie sur Entrée
2. Ferme la fenêtre PowerShell/terminal
3. Relance ton IA avec le fichier Lancer Claude Code.ps1 sur ton Bureau

L'IA répond lentement ou "timeout"

Ce qui se passe : Le modèle gratuit est saturé (trop d'utilisateurs en même temps). Les modèles gratuits ont des files d'attente.

Solutions :
1. Essaie /model et passe sur Llama 3.3 70B (meta-llama/llama-3.3-70b-instruct:free) — il est souvent plus disponible
2. Le Qwen3 Coder est aussi une bonne alternative quand DeepSeek est saturé
3. Évite les heures de pointe (soirées) si possible
4. Tape /clear pour réduire la charge de la conversation

ℹ Avant d'ouvrir OpenRouter
Limites quotidiennes des modèles gratuits (:free)
Sur OpenRouter, la limite de requêtes/jour des modèles :free dépend des crédits que tu as achetés : moins de 10 crédits achetés → 50 requêtes/jour ; à partir de 10 crédits achetés → 1000 requêtes/jour.
