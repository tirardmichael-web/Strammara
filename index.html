Claude Code Auto-Setup
Gratuit Populaire Windows
> Une IA de code gratuite installée en 3 clics,
> Zéro ligne de commande — ton compte OpenRouter + un fichier .ps1,
> Détection automatique des outils déjà installés (VS Code, Node, Git),
> Catalogue OpenRouter en direct : choisis ton IA préférée,
> Menu de démarrage multi-IA : une clé, plusieurs modèles.
Tu veux coder avec une IA sans te prendre la tête ? Ce fichier PowerShell installe tout automatiquement — VS Code si nécessaire, Node.js, Git, Claude Code — et configure ta clé OpenRouter en une fois. Tu n'écris aucune commande.
  • Installation en 3 clics
  • Détection intelligente des outils
  • Choix de l'IA dans un menu
  • Une seule clé OpenRouter
  • Compatible Windows 10/11
  • Mise à jour sans réinstaller
